# 🏰 塔防游戏 - 保卫基地

一款基于 HTML5 Canvas 开发的经典塔防游戏，支持多种防御塔类型、波次系统和等级成长机制。

## 🎮 游戏特色

- **多种防御塔类型**：箭塔、炮塔、减速塔、激光塔、毒塔，每种都有独特的攻击方式和升级路线
- **丰富的敌人类型**：普通怪、快速怪、坦克怪、攻击怪、BOSS，各具特色
- **波次系统**：敌人波次逐渐增强，挑战玩家的策略布局
- **等级成长**：通过击杀敌人获得经验，解锁更强大的防御塔
- **排行榜系统**：记录最高分，与其他玩家一较高下
- **响应式设计**：支持桌面和移动设备

## 🚀 快速开始

### 本地运行

1. 克隆或下载项目到本地
2. 直接在浏览器中打开 `index.html` 文件
3. 开始游戏！

```bash
# 或者使用简单的 HTTP 服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🎯 游戏玩法

### 基本操作

| 操作 | 说明 |
|------|------|
| 点击防御塔图标 | 选择要建造的防御塔类型 |
| 点击地图空白处 | 建造选中的防御塔 |
| 点击已建造的塔 | 查看信息/升级 |
| 空格键 | 开始下一波敌人 |
| P 键 | 暂停/继续游戏 |
| ESC 键 | 取消当前选择 |

### 防御塔介绍

| 防御塔 | 解锁等级 | 特点 |
|--------|----------|------|
| 🏹 箭塔 | 1 | 基础防御塔，攻速快，成本低 |
| 💥 炮塔 | 2 | 高伤害，范围攻击 |
| ❄️ 减速塔 | 3 | 减速敌人移动速度 |
| ☠️ 毒塔 | 4 | 持续毒素伤害 |
| ⚡ 激光塔 | 5 | 持续伤害，穿透攻击 |

### 敌人类型

| 敌人 | 特点 |
|------|------|
| 普通怪 | 平衡的属性 |
| 快速怪 | 速度快，生命值低 |
| 坦克怪 | 生命值高，速度慢 |
| 攻击怪 | 可以攻击防御塔 |
| BOSS | 强大的敌人，每几波出现 |

## 🛠️ 技术栈

- **HTML5 Canvas** - 游戏渲染
- **原生 JavaScript (ES6+)** - 游戏逻辑
- **CSS3** - 界面样式
- **LocalStorage** - 数据持久化

## 🎨 自定义配置

可以通过修改 `js/config.js` 文件来调整游戏参数：

- `GRID` - 地图网格大小
- `INITIAL` - 初始资源
- `TOWER_TYPES` - 防御塔属性
- `ENEMY_TYPES` - 敌人属性
- `WAVE` - 波次配置
- `LEVEL` - 等级系统配置
